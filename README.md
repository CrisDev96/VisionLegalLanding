# Vision Legal Abogados - Landing Page

## Descripción
Landing page diseñada para la firma de abogados "Vision Legal Abogados". El objetivo principal de este proyecto es atraer nuevos clientes como un canal de adquisición digital, facilitando el contacto a través de WhatsApp o de un formulario integrado.

## Tecnologías Utilizadas
* HTML
* CSS
* JavaScript

## Características del Proyecto
* **Optimización SEO:** Implementación de buenas prácticas para mejorar la visibilidad orgánica en buscadores.
* **Front-end Atractivo:** Diseño web básico, pensado para captar la atención de clientes potenciales mostrando profesionalismo y confianza.
* **Medios de Contacto:** Opciones directas para comunicarse, ya sea vía WhatsApp o diligenciando el formulario de contacto de la landing page.

## Proceso de Desarrollo
1. **Diseño Inicial:** Se comenzó utilizando un template base creado en Stitch.
2. **Integración:** El template se pasó a Antigravity para personalizarlo e integrarlo de acuerdo a las necesidades de la firma.
3. **Próximos Pasos (En curso):** El siguiente paso en el flujo de desarrollo será integrar JavaScript para poder controlar y manejar el formulario de contacto, así como la integración con la API de WhatsApp para que los métodos de comunicación del usuario queden operando.

## ¿Qué he aprendido?
* **Uso de Inteligencia Artificial (IA) en el Desarrollo Web:** He comprobado que las herramientas de IA son extremadamente útiles como apoyo, en especial para el diseño UI/UX, área en la cual no destaco mucho. Me han permitido materializar y dar continuidad a mis ideas sin que la falta de fluidez estética sea un impedimento.
* **JavaScript Práctico:** He aprendido los fundamentos de JavaScript y cómo implementarlos en un proyecto real para realizar integraciones valiosas, como el enlace hacia el ecosistema de Google y las interacciones para WhatsApp.

## Posibles Mejoras
A medida que el proyecto crezca o los requerimientos de la firma aumenten, una mejora natural sería **migrar el proyecto a una tecnología más moderna y robusta, como React o Vite**, lo que permitiría que la aplicación web sea más escalable, eficiente y fácil de mantener a largo plazo.
